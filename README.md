## 게임 소개

Hell Pit은 1.44MB 공모전의 용량 제한에 맞춰 제작한 C++ 기반 후크 액션 게임입니다.

플레이어는 아래에서 추격하는 괴물을 피해 수직 갱도를 오릅니다. 지형과 적, 투사체 등 다양한 대상에 후크를 걸어 이동하고 전투를 이어가며, 아이템과 특전으로 플레이 방식을 바꿀 수 있습니다.
